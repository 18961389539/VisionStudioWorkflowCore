# Caliper Edge 节点

节点类型为 `measure.caliper`。在节点配置中可切换“选线与调参”和“边缘剖面诊断”。

## 选线与调参

- 图像工具栏支持重绘、拖动端点、移动整条搜索线和“定位搜索线”。定位只调整视图，不修改参数。
- 快捷设置支持水平、垂直、旋转 ±15°、交换端点和撤销最近一次快捷调整。撤销只恢复端点，保留后来修改的采样参数。
- 阈值与投影长度支持滑块、数值输入和单项恢复默认。偶数投影长度按下一个奇数执行，并显示实际宽度。
- 蓝色端点对应 `startX/startY`，紫色端点对应 `endX/endY`。选择“从终点”时，箭头反向，端点颜色和极性定义保持不变。
- 极性始终按起点→终点定义。“从起点/从终点”在合格候选中选择第一条，“最强”选择绝对响应最大的一条。
- 上游 `searchLine` 几何只读；基准几何只在匹配的图像坐标系中编辑，当前映射视图用于核对。

## 边缘剖面诊断

运行节点后读取本次真实采样。灰度经过实际灰度转换、ROI 投影平均和搜索线裁切；候选来自同一次算法调用。

- 横轴为距原始搜索线起点的距离，包含被图像边界裁去的起始距离。
- 灰色区域为无效采样，ROI 缺口两侧独立检测；缺口不会连成一条假梯度。
- 蓝线为投影灰度，浅灰线为相邻灰度差参考，紫色标记为合格候选，绿色为最终选点，橙虚线为阈值。
- 阈值作用于算法实际响应；相邻灰度差不能直接代替高斯滤波后的候选响应。
- 曲线游标和“候选详情”中的定位按钮可在图像中显示对应位置；查看候选不会改变算法选点。
- 未检出时区分搜索线在图像外、裁切后过短、ROI 无有效采样、连续采样不足及无合格候选。
- 参数修改后明确显示“诊断已过期”。快照以运行 ID、节点 ID 和执行序列绑定，重新运行后更新。

诊断仅在交互式图像捕获开启时保留，与圆卡尺共享每次运行 16 MiB 的剖面预算，并计入运行缓存的总预算。生产运行默认不保留剖面；读取诊断不会再次执行流程或设备。
