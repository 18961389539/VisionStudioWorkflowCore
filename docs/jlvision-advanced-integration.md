# JLVision 专项算子接入（2026-10-19）

本轮范围为审核列出的专项能力及三个现有接入问题。保留现有节点类型 ID，新增 9 个节点、42 种操作入口；这不是对 JLVision 全部导出 API 的覆盖率声明。

| 节点 | 类型 ID | 操作入口 |
| --- | --- | --- |
| 亚像素特征提取 | `jlvision.featureExtract` | 高斯/曲面/彩色线条、灰度/彩色亚像素边缘、Harris/Förstner 角点、边缘线段（8） |
| 高级区域分割 | `jlvision.segmentation` | 分水岭、标记分水岭、阈值分水岭、MSER（4） |
| 区域关系与距离分析 | `jlvision.regionAnalysis` | 距离变换、最近点变换、空间关系、方向关系、邻居、骨架线段（6） |
| 矩形轮廓拟合 | `measure.fitRectangle` | `FitRectangle2ContourXld`（1） |
| 几何求交 | `geometry.intersections` | 直线圆、圆圆、线段线段（3） |
| DXF 轮廓读写 | `jlvision.dxf` | 导入、导出（2） |
| 标定平面映射 | `jlvision.worldPlane` | 图像投影、生成坐标图、重复应用坐标图、轮廓投影（4） |
| 图像修复与复原 | `jlvision.restoration` | 调和插值、CT/MCF/CED/各向异性修复、维纳/噪声估计维纳、运动/离焦 PSF（9） |
| 灰度表面重建 | `jlvision.surface` | Pentland/原始局部/改进局部重建、高度场渲染、梯度积分（5） |

## 数据与操作

- 原生 XLD 输出保留双精度坐标、开放/闭合状态和逐点数值属性（例如线宽）。通用轮廓操作及轮廓属性计算不再将几何坐标取整；预览绘制仍按屏幕像素绘制。原生属性在将平台轮廓重新构造成 XLD 时不会恢复，后续算子只保证坐标与单位传递。
- 特征提取的 `contours` 用于后续轮廓分析；角点还输出 `detections`，可通过已有集合选择/循环节点取出每个点。`point` 从零开始按序号选择，越界时省略；`points` 保留全部点 JSON。Förstner 协方差在 `details` 中。
- 分水岭主区域为盆地，辅助区域为边界。MSER 主/辅助区域分别为暗/亮区域，`count` 与 `found` 描述主区域。
- 区域关系返回的对象序号统一从零开始。方向关系表示 `region2` 相对于 `region` 的方向。此包欧氏距离图的数值为原生整数像素量化值；不伪称连续亚像素距离。
- 计量矩形输出位置是中心、宽高是完整尺寸，角度与现有图像坐标约定一致。它用于拟合边缘；已有旋转外接矩形节点仍可用于计算包围范围。
- 交点列表和选中点都保留浮点坐标。无限直线与有限线段分为不同操作，重合情况另由 `overlapping` 表达。编译时检查可追踪输入几何的坐标系是否一致。
- DXF 可显式缩放、翻转 Y 轴及偏移；导入单位缺省为 `unspecified`，须按实际 CAD 单位设置，不视为图像像素。导出保留坐标数值，要求轮廓单位与坐标系一致；不自动写入 CAD 单位头。导出使用临时文件后原子替换，默认禁止覆盖。导入上限 100 MB、最多 10000 条轮廓和 200 万个点。
- 标定平面映射接受内参节点输出的原生相机模型 JSON，或原生相机参数数组。平面位姿为 7 项 JLVision 位姿，平移使用米、角度使用度。轮廓按选择的物理单位输出并附带单位/坐标系元数据；图像仍用输出像素表示，每像素物理尺寸由 `pixelSize` 指定。
- 生成的映射拆成 `mapRows` / `mapColumns` 两张实数坐标图，配套输出 `mapInfo`（生成节点、原图/映射尺寸、单位、采样尺寸、标定/位姿指纹和两张映射内容指纹）。`applyMap` 必须配套连接三个端口；编译器校验同一生成节点及图像坐标来源，运行时校验尺寸、类型和内容指纹。映射后的图像建立独立坐标系，不能直接复用原图 ROI。
- 修复区域与图像必须同尺寸。维纳复原需要与原图同尺寸的实数 PSF；`filteredImage` 是原图的平滑版本，不是噪声本身。生成 PSF 时对原生核能量归一化。
- SFS 明暗重建需要 8 位单通道图；高度场渲染及梯度积分使用实数图。SFS 输出是依赖反射假设的相对高度，不是经过标定的绝对 3D 测量。

## 现有流程兼容

- `jlvision.imageOp.compose3` 和 `rgb3ToGray` 使用独立的 `image` / `image2` / `image3` 三个单通道输入。原先重复第二通道的配方需要补接第三通道，缺失会在编译及运行时明确报错。
- `lutTrans` 使用可编辑的 256 项整数 JSON 查找表。旧配方没有 `lutJson` 时保留恒等映射，新配方可自定义映射；非法长度、非整数及越界值被拒绝。
- 新增的 `PortDescriptor.requiredWhen` 是可选目录字段，描述随操作变化的必要输入。编译器、前端预检与节点画布共同消费该字段，保留既有 `required` 行为。
- 所有新节点已注册到依赖注入、运行时节点注册表及生成目录。显示名、参数、选项与新增端口均有中文。

## 验证

`JlVisionAdvancedIntegrationTests` 覆盖全部操作分支的原生执行、已知交点、分数矩形中心、DXF 往返与覆盖保护、最近点坐标、三独立通道、非恒等 LUT、映射复用与直接投影一致、无输入 PSF 编译、条件必要输入，以及轮廓属性的亚像素质心。

接入阶段（下述设计修复之前）的历史验证结果：Engine 非长时测试 1623 项通过，其中专项集成测试 56 项；API 测试 405 项通过；前端 41 个测试文件、528 项通过。合成图与数值回归不代替现场图片的精度验收。这些数字不代表设计修复后的回归结果。

## 节点设计修复

- 轮廓特征新增 `selectedIndex` 和 `secondIndex`，显式选择主、参考轮廓。`contour`、`pointCount`、叠加图仅对应主轮廓；`inputCount` 保留整组数量。缺省仍选第 0 条；空参考集合及序号越界明确报错。
- 通用几何 `point` / `points` 输出计算出的二维点（求交、投影、椭圆点、直线中心）。平行求交不输出点。`count` / `found` 描述结果点，原有字段数量改用 `componentCount`；输入点移到 `inputPoints` 调试端口。旧流程若使用这些输出需确认新含义。
- 骨架线段和边缘线段统一构造完整长度、包围框和最小外接圆。
- MSER 新增 `darkRegion` / `lightRegion`、明暗计数；`count` / `found` 覆盖两组结果。兼容原 `region`（暗）和 `secondaryRegion`（亮）；分水岭仍只统计盆地区域，边界不计入总数。
- 矩阵节点新增 `matrixA` / `matrixB` 输入，可直连上游 `matrix` 输出，接线优先于参数。未接线时使用表格或 JSON 编辑；表格支持最多 20×20，较大矩阵保留 JSON。原有字符串序列化契约不变。
- 通用轮廓生成模式不再要求虚设输入轮廓，其他操作通过 `requiredWhen` 保持必要输入校验。
- 旧的映射应用流程必须补接同一生成节点的 `mapInfo`；禁止两张映射混接或跨来源坐标系复用。

本轮仅进行编译构建与目录生成，未新增或运行测试。

## 持续改进：参数、数据与资源约束

- 曲面线条窗口和线段梯度窗口在界面以 2 递增，执行时拒绝偶数。线段最小幅值要求整数，取消小数静默截断。
- PSF 生成可选接入 `image` 自动匹配原图尺寸；未连接时继续使用手动宽高。自动匹配时隐藏尺寸编辑，实际尺寸由 `width` / `height` 输出。维纳复原明确校验单通道实数 PSF 和同类型、同尺寸的平滑参考图。
- 模糊核使用独立坐标系，不能因尺寸匹配而视为原图坐标。编译器、运行时和前端的坐标追踪保持一致；标定平面映射的 ROI 来源指纹包含所接标定、平面位姿及映射描述的依赖。
- 表面重建严格校验灰度、实数类型、梯度尺寸和非有限值；重建结果由 `heightField` 输出（相对高度），渲染结果由 `shadingImage` 输出（亮度）。`resultKind` / `unit` 显式区分结果含义，原有 `image` 端口保留。图像别名共享同一受工作流管理的资源，不重复复制像素。
- 矩阵创建、重复、乘法、求解和全 Q 分解在调用前检查结果规模，最多 100 万元素；结果中的非有限数值明确报错。修复矩阵分解附加句柄的释放。热力图最多显示左上 128×128 个单元，调试曲线最多 64 个归一化采样点，完整结果仍在 `matrix`。目录移除并未实际提供的 SVD 和一般特征值宣传。
- 几何、轮廓特征及通用轮廓算子的调试图使用有界视口，最大 1024×768，支持负数和大坐标；原始几何值不变。诊断中的 `previewTransform` 给出预览缩放与偏移，不应把调试图像坐标当作原始坐标。
- 轮廓不再静默抽样到 20000 点，改为在总点数 200 万预算内完整保留；单节点显式预算超限时报错。逐点属性使用 JLVision 原生序列化快照保留，恢复时检查点列、闭合状态、属性及快照内容指纹。快照是托管字节，不携带原生句柄；单条快照最多 64 MB。报告快照不输出内部二进制，工作流内部仍保留。旧的带属性但无原生快照数据需要重新提取，不能静默去掉线宽等属性。
- 调优面板隐藏已被接线覆盖的矩阵参数；表格无法展示的大矩阵和非法 JSON 不再显示误导性的模式切换按钮。

以上改进仍仅进行构建及目录生成，未运行原生回归或测试。

当前内置节点总数为 171。接入代码和生成目录在重启后端后加载到运行实例。
