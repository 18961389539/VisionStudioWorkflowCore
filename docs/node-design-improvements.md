## 使用计量模型

1. 连接输入图像，打开计量模型配置，点击“获取输入图像”。
2. 选择绘制直线、圆、椭圆或旋转矩形；也可添加对象后填写坐标。
3. 单击选中对象，拖动移动；白色控制点调整端点或尺寸，角度在数字字段中调整。
4. 为对象取唯一名称，设置全局或逐对象的边缘参数，再运行节点。
5. 蓝色为选中对象，绿色为基准对象，黄色为运行产生的实测结果。
6. 将“结果列表”连到“提取计量结果”，按对象名称或从 0 开始的序号提取结果。

启用姿态或固定对齐时，对象使用基准坐标，当前图像仅叠加实测结果；图上绘制锁定，仍可编辑数值。绘制基准对象应先关闭对齐。椭圆的矩形输出表示带方向的外接矩形，`kind` 仍为 `ellipse`。

## 旧流程兼容

- 类型 ID 保留；两个找边入口继续存在。卡尺找边保留阈值 12、不细化的历史默认值；亚像素找边保留阈值 8、抛物线细化的默认值。
- 差分的 `diffMode` 在缺少 `mode` 时迁移。旧 `clip` 曾未参与执行，因此继续忽略；需要 8 位输出时显式选择 `outputType=byte`。
- HTTP 显式 `retries` 优先；只有旧 `retryPolicy` 的流程会迁移为 0/1/2 次额外重试。
- 保存图像默认不覆盖；旧流程显式保存的 `overwrite` 值继续生效。
- 计量模型保留 `measurements` JSON；新增的 `results` 与建模对象一一对应，包括未成功添加或未测量到的对象。
- 算子表单保留序列化参数键，切换操作不删除其他操作的已存参数。

## 维护与验证范围

修改算子表后运行 `python scripts/generate-operator-forms.py`，再生成前端目录。新增算子缺少消费参数元数据，或消费参数缺少目录描述时，目录构建会明确报错。

本轮执行前端生产构建、后端 API 构建和服务健康检查。没有运行自动化测试，也没有现场相机图像验证；编译通过不代表现场精度与全部交互已验收。

## 区域灰度统计

- 统计范围固定为输入区域并集与图像有效域的交集，重叠像素只计一次；`image` 输出仍为有效区域二值掩膜。
- 标称均值容差、最低/最高均值、最大总体标准差、最大变异系数和最小有效面积共同参与 `withinTolerance`。0 关闭对应条件，边界值包含在合格区间内；上下限倒置、标称容差区间与上下限无交集时拒绝配置。
- 灰度阈值支持到 65535，统计保留输入灰度量纲。CV 使用标准差 / |均值|，0.1 表示 10%；非空区域均值为零且存在波动时省略 `cv`，输出 `cvDefined=false` 和一个警告；启用最大 CV 时判为不合格。
- 统一使用 `emptyPolicy`：`zeros` 返回 `found=false`、`withinTolerance=false`、`pixelCount=0` 和零统计；`fail` 报错。未设置此策略时兼容旧 `requireNonEmpty`，显式策略优先；前端加载和编辑时迁移旧开关。
- `pixelCount`、`withinTolerance`、均值/标准差/极值/极差始终提供；新增 `cvDefined` 和 `warningCount`。标准/详细诊断列出测量值、阈值、有效区域口径和 `failedGates`，便于区分未找到区域与统计超限。
- 面板按均值判定、波动判定、有效区域和结果分组。历史 `sampleMode`、`statSet`、计算重试保留为内部兼容字段，始终输出完整统计，避免旧连接因选项而缺少端口。

兼容影响：旧配方中已填写但原先未生效的均值/标准差/面积限制现在参与判定；默认空区域由省略统计改为输出零统计，并明确判为不合格。`cvDefined=false` 时不能将 CV 当成有效测量值。
