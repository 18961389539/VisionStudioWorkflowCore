# 保存图像：连续归档

## 文件命名与冲突

新建“保存图像”节点默认使用基础文件名、主机本地时间戳和短保存标识，例如 `output_20261019_153000_1234567_a1b2c3d4.png`。同名文件默认另存唯一文件，也可选择报错、跳过或显式覆盖。文件在目标目录内写入临时文件后，通过原子移动发布，发布时再次处理同名冲突。

模板不含目录和扩展名，扩展名沿用基础保存路径。支持：

| 占位符 | 内容 |
| --- | --- |
| `{timestamp}` / `{date}` | 主机本地时间，分别为 `yyyyMMdd_HHmmss_fffffff` / `yyyyMMdd` |
| `{runId}` | 当前流程运行 ID；独立执行且未提供运行 ID 时退回本次保存 ID |
| `{saveId}` | 每次节点调用的唯一 ID；同次 IO 重试保持不变 |
| `{nodeId}` | 节点 ID |
| `{result}` | `OK` / `NG`，需要连接“检测合格”输入 |
| `{partId}` | 产品编号，输入优先于参数；使用时不能为空 |
| `{sequence}` | 上游非负整数序号，至少补齐六位；节点不自行维护计数器 |

例如 `{partId}_{sequence}_{result}_{saveId}`。元数据中的非法文件名字符会替换并附加内容指纹，防止不同编号清洗为同名文件。未知占位符、目录分隔符、保留设备名和过长文件名会明确报错。同名另存使用随机唯一后缀；过长的基础名会缩短以容纳该后缀。

## 分类与接线

- “保存范围”支持全部保存、按 OK/NG 分类、只保存 OK、只保存 NG。后三种需要连接“检测合格”布尔输入；只保存某类也使用对应结果子目录。
- 开启按日期分目录后，输出目录形如 `归档根目录/2026-10-19/NG/文件名.png`。
- “基础保存路径”和“产品编号”可接线，接线时隐藏被覆盖的参数。
- 参数按归档命名、编码与像素、尺寸限制、失败与诊断分组。

## 输出与失败行为

`saved` 表示是否新写入文件，`path` 为最终目标路径。被筛选、空图跳过和同名跳过时，路径不代表本次创建了文件，应先检查 `saved`。`reason` 分别返回 `saved`、`result-filtered`、`empty-image-skipped` 或 `exists-skipped`。筛选掉的图像不编码、不创建目录和文件。

诊断记录请求路径、实际文件名、运行 ID 来源、保存 ID、含时区的时间、分类、冲突次数和文件写入尝试数。通用 `attemptCount` 至少为 1，表示节点尝试次数；未写入时诊断中的 `fileWriteAttempts` 为 0。重试只覆盖临时文件写入和发布的 IO 异常，参数、编码和目录创建失败直接报错。取消时清理临时文件。

## 旧流程兼容

缺少新命名参数的旧节点继续使用固定路径；旧 `overwrite` 映射为覆盖或报错。前端加载、编辑和后端直接执行均保留这一语义。只有新建节点默认使用时间戳和另存策略。显式 `conflictPolicy` 优先于旧 `overwrite`。

本轮仅进行目录生成和编译构建，未新增或运行测试，也未执行真实图像归档。运行实例需加载新的后端构建后才具备上述行为。
