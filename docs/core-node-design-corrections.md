# 基础节点设计修复（2026-10-19）

本轮只处理审查清单的前四项：点线距离、PLC 视觉结果写入、灰度范围分割和 HTTP 请求。其余拟合质量、图像归档和 CSV 表格设计不属于本轮范围。

## 点到直线／线段距离

- `distance` / `closestPoint` 对应所选无限直线或有限线段。
- `rawProjectionT` 和 `projectedPoint` 是无限直线上的原始投影参数与垂足；`withinSegment` 始终按原始参数判断。
- `projectionT` 保留实际采用的参数：线段模式可能裁剪到 0..1，`projectionClamped` 表示是否发生裁剪。
- `lineDistance` 为无限直线垂距；原有 `signedDistance` 始终为到有向无限直线的垂距。沿 X 正向的水平线，图像下方点的值为负，反转端点后符号反转；不将其解释成端点有向距离。移除原先没有作用的 `signed` 开关，两个距离输出均保留。
- 例如点 (20,3) 与线段 (0,0)→(10,0)：原始参数为 2，线段模式实际参数为 1，`withinSegment=false`，最近点为 (10,0)，线段距离为 √109，直线垂距为 3，有向垂距为 -3。

## PLC 视觉结果写入

- 保留 Ready=0 → OK/NG 和启用坐标 → Ready=1 的设备互斥写入顺序。
- 空 `xTag/yTag/rTag` 禁用该字段；Ready 与 OK 标签仍为必填，各启用标签不得重复。
- `missingCoordinatePolicy` 明确处理启用字段的缺失输入：`skip` 默认跳过，`fail` 在写入前拒绝整次操作，`zero` 显式写零。所有标签、缺失策略和有效坐标在设备写入前校验。
- 仅实际写入的坐标才输出 `x/y/r`；`xWritten/yWritten/rWritten` 始终输出，`tagsWritten` 是实际写操作次数（含 Ready 的两次），诊断列出已写与跳过字段。
- 移除未实现的 `payloadFormat/onOverflow` 控件和读取；旧流程中的同名参数不再产生效果。
- 兼容性：旧流程未连接坐标时曾自动写零，现在默认跳过。确实需要零值的流程请显式选择 `zero`；依赖坐标输出的后续节点应检查对应已写入标志。

## 灰度范围生成区域

- `region.fromRange` 的灰度模式与 `region.fromThreshold` 共用同一执行器，按原像素单位使用闭区间，不缩放到 8 位。
- 支持范围：byte 0..255、uint2 0..65535、int2 -32768..32767、int4 为 32 位有符号整数范围、real 为有限的 32 位浮点范围。
- 下限必须不大于上限，且阈值须处于实际输入类型的可表示范围；实数输入拒绝 NaN/无穷值。8 位 BGR/BGRA 转灰，单通道数值图保留位深。
- 目录范围覆盖所支持类型的并集，最终约束随实际图像校验；诊断和概要包含 `pixelType/grayLowerLimit/grayUpperLimit`。缺省阈值仍为 128..255，不自动改写已有配方。

## HTTP 数据输入与重试

- 新增可选 `url`、`body`、`value`、`idempotencyKey` 数据输入。接线覆盖相应参数；界面隐藏已被覆盖的参数。
- `body` 原文与 `value` JSON 二选一；后者发送实际值的 JSON 并使用 application/json。轮廓请求不携带内部原生快照。图像、限定域图像、帧组和控制值不能作为通用 JSON 数据提交。
- GET/HEAD 不接收正文。请求发送前按 UTF-8 字节检查 `maxRequestBytes`，响应按 `maxResponseBytes` 完整读取或明确报错，不返回截断内容。
- `retries` 是额外尝试次数。默认仅 GET/HEAD 可按该设置重试；POST/PUT/DELETE 须开启 `retryWriteRequests` 并提供幂等键才允许自动重试。未开启时即使旧配置设置了重试次数，也只发送一次，并在诊断标记重试被抑制。
- 同次重试复用相同 `Idempotency-Key`。键应在每个业务操作间唯一、同一业务重试间稳定，可由上游产品编号等生成；服务端必须实现去重。此机制不能保证不支持幂等键的服务只执行一次，外层流程重跑也需要复用该业务键。
- 仅传输错误、尝试超时、408/429/5xx 进入重试；其他状态失败后不重试。外层取消直接传播。超时是每次尝试的时限。
- 诊断包含请求数据来源、请求字节数、配置和实际重试、是否提供幂等键，不输出键值或请求正文。

## 构建范围

同步后端目录和生成的前端目录，进行前后端编译构建；本轮未新增或运行测试，未向设备写入或发送实际 HTTP 请求。运行实例需加载新的后端构建后才具备这些行为。
